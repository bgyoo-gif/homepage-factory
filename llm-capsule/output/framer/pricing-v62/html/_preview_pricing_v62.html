Pricing FAQ

Common questions

How is pricing calculated?

Volume-based on monthly document processing throughput, with adjustments for deployment mode (air-gapped on-prem typically has different cost structure than cloud), regulatory profile (additional compliance audit hours), and connector library scope. Workflow Proof of Value is a fixed-fee, one-workflow evaluation; Enterprise is annual license; AWS Marketplace is listed pay-as-you-go with EDP / private offer eligibility for committed volume.

Can we start with a Workflow Proof of Value and convert to Enterprise?

Yes. Workflow Proof of Value is designed as a 4-8 week evaluation on one real production workflow that produces a deployment fit report. PoV contracts include a conversion path to Enterprise with credit applied; most customers convert in 6-12 weeks after PoV kickoff.

Do you support custom on-prem deployments?

Yes. Air-gapped on-prem and on-prem hybrid (Capsule on-prem + approved external LLM) are first-class deployment modes. Telecom-grade and OT-grade environments are supported. Validated at SK Telecom (telecom NOC), EUMC (hospital), and Ministry of National Defense (mission workflows).

What about EU sovereign data and GDPR?

Path A supports in-region EU LLM endpoints (EU-hosted Anthropic, OpenAI EU, Mistral EU). Path B supports fully on-prem inside the EU. Both paths feed audit logs that align with GDPR Articles 5, 17, 30, 32. Standard DPA + SCC are provided as part of Enterprise contract. Recognized at Deutsche Telekom T Challenge 2026 — Top 12 in Data Security & Governance.

Where can LLM Capsule be deployed?

Six deployment modes: on-premise, air-gapped, hybrid, VPC / private cloud, AWS Marketplace, embedded SDK, and Slack App. Telecom-grade (NFV / container / multi-region) is offered as a deployment variant for operator infrastructure. See the Architecture page for details.

What certifications does LLM Capsule hold?

ISO/IEC 27001, ISO/IEC 42001, KISA Fast Track, GS Certification, plus awards and recognition from MSIT Security Innovation, Deutsche Telekom T Challenge, AI Medical Innovation, Startup World Cup, Next Rise, Gartner, and Emerging AI+X. See the Trust Center for full list.
