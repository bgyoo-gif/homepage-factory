## Section 02: Definition

Definition
정의

Operational data is the structured and unstructured enterprise data generated by ongoing business operations. It includes the records, logs, configurations, alarms, tickets, runbooks, workflows, and contextual references that operations teams produce and consume daily.
운영 데이터는 지속적인 비즈니스 운영 과정에서 생성되는 정형·비정형 기업 데이터입니다. 운영 팀이 매일 생산하고 소비하는 레코드, 로그, 설정 파일, 알람, 티켓, 런북, 워크플로우, 그리고 상황별 참조 정보를 포함합니다.

## Section 03: Article Body

<h2>운영 데이터가 아닌 것</h2>

<p>운영 데이터는 PII와 같지 않습니다. PII는 이름, 연락처, 금융 식별자처럼 개인을 특정할 수 있는 필드입니다. 운영 데이터는 PII를 부분 집합으로 포함할 수 있지만, 민감성은 주로 구조, 순서, 집계 패턴에서 비롯됩니다.</p>

<h2>산업별 예시</h2>

<h3>통신</h3>

<li>Network topology, device IDs, site IDs, circuit IDs, IP ranges</li>
</ul>

<li>Alarm sequences, traffic anomaly patterns</li>
</ul>

<li>Incident records with customer-impact and SLA risk</li>
</ul>

<li>NOC response history, runbooks, change management records</li>
</ul>

<h3>OT / 산업</h3>

<li>Asset IDs, PLC/ICS alerts, vulnerability records</li>
</ul>

<li>Plant operation context, patch constraints</li>
</ul>

<li>Vendor and device references</li>
</ul>

<h3>의료</h3>

<li>Clinical workflow, lab result flow, prescription flow</li>
</ul>

<li>Hospital operation records, claim review context</li>
</ul>

<h3>국방 / 공공</h3>

<li>Mission logs, operation briefs</li>
</ul>

<li>Access-controlled context, command workflow</li>
</ul>

<h3>금융 / 보험</h3>

<li>Risk review, transaction anomaly</li>
</ul>

<li>Audit trail, approval workflow, internal control evidence</li>
</ul>

<h2>데이터 레이어가 필요한 이유</h2>

<p>운영 데이터는 구조(토폴로지 자체가 네트워크를 드러냄), 순서(알람 패턴이 장애 연쇄를 노출함), 집계(인시던트 빈도가 고객 세그먼트를 노출함)를 통해 정보를 유출합니다. PII 필터링으로는 이 유출을 차단할 수 없습니다. <a href="/resources/glossary/ai-ready-operational-layer">데이터 레이어</a>는 <a href="/resources/glossary/structure-preserving-encapsulation">문서 구조 보존 캡슐화</a>와 <a href="/resources/glossary/differential-privacy">차등 프라이버시 기반 보호</a>를 적용하여 운영 데이터를 LLM 워크플로우에 안전하게 연결합니다.</p>

<h2>핵심 문장</h2>

<blockquote>운영 데이터는 비즈니스가 실제로 돌아가는 데이터입니다. AI는 PII 가드레일만으로 여기에 닿을 수 없습니다. 데이터 레이어는 바로 이 범주를 위해 만들어졌습니다.</blockquote>
