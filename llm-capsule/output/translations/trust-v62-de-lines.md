Jedes Ereignis im LLM Capsule-Lebenszyklus wird mit strukturierten Metadaten protokolliert. Die Aufzeichnungen stehen Datenschutz-, Sicherheits- und Compliance-Teams zur Prüfung bereit.

Erkennungsereignisse

Every detection: which marker, which document, which version, confidence, timestamp. Reproducible across policy versions.
Jede Erkennung wird erfasst: welcher Marker, welches Dokument, welche Version, Konfidenzwert, Zeitstempel. Die Ergebnisse sind über alle Richtlinienversionen reproduzierbar.
